# 水印选择页场景

watermark_leica/standard/tag/classic/film.webp 来自用户提供的 MiMediaEditor.apk 的 assets/watermarks/<category>/img_setting_base.webp，均为720×720、无预先绘入水印的原始场景。

用于本应用的模板预览实际渲染，不替换用户导入的照片。新预览由统一水印绘制器重新生成，属于本产品适配，并非声称复制了参考APK的私有运行时渲染结果。

App 默认示例使用现有 watermark_standard.webp（720×720）。旧版捆绑 JPG 示例草稿仅迁移到此现有场景，用户照片路径不变。
